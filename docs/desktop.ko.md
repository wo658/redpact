# 데스크톱 배포 종료

Windows·Linux·macOS 네이티브 데스크톱 배포가 종료되었습니다. 새 네이티브 설치 파일,
Homebrew Cask, 서명된 updater 릴리스는 제공하지 않습니다. 기존 GitHub 자산은 과거
자료로 유지하며 지원하는 새 설치 경로가 아닙니다.

[npm/pnpm 또는 App Page Plugin](installation.md)을 사용하세요. 두 경로 모두 같은 웹
앱과 런타임을 제공합니다. `app/desktop` 소스는 참고용으로 남으며 버전은 웹 런타임
릴리스와 연동하지 않습니다. 네이티브 릴리스 workflow는 제거했습니다.

같은 포트에서 다른 서버를 시작하려면 기존 데스크톱 인스턴스를 먼저 종료하세요.
새 설치는 기존 설정과 실행 근거를 삭제하거나 자동 이전하지 않습니다. 원래 데이터
디렉터리를 보존하고 두 인스턴스가 같은 상태를 동시에 사용하지 않도록 하세요.
데이터와 마이그레이션 규칙은 [저장소](storage.md)를 참고하세요.
