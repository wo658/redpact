## English

Redpact now prioritizes its GPT-embedded viewer and test-environment management experience.

- Replace workspace tabs with a shared one-row header in Desktop Full and Half View. Keep navigation and viewer controls compact; use Unit and Integration labels and a shared Play action at the far right.
- Start the embedded viewer with its sidebar collapsed at every width. Preserve manual toggles during resizing and reset to collapsed when reopening.
- Move noncritical diagnostics into dismissible bottom-right notices and the Problems history in Settings. Blocking connection failures retain recovery controls.
- Recognize squash/rebase PR integration using the exact source head, repository and base, plus the merge result already present in the configured local main branch. Preserve new commits and dirty worktrees. Git Graph keeps genuine Git parent edges.
- Introduce dev/main delivery: dev verifies changes; main automatically prepares a stable version, verifies the exact snapshot, tags it, publishes the verified npm artifact and confirms registry integrity.
- Retain safer runtime migrations, original backups, configurable Git-output limits and execution diagnostics from the previously unpublished 0.10.0 snapshot.

Verification is attached to the exact release workflow and artifact identity. Local and managed acceptance cover the affected viewer and merge-tracking flows; the release workflow verifies the installable package on Ubuntu/Node 24. Real ChatGPT host capability enforcement and other OS/Node combinations are outside that evidence. GitHub PR fallback requires authenticated gh; unsupported or unavailable evidence leaves work visible.

Upgrade the installed runtime and reconnect the host after Plugin/schema changes. A Plugin that pins an unpublished or absent runtime shows Install Redpact; an installed global CLI is separate from the Plugin-managed runtime. Existing settings and historical execution evidence are preserved. No project-settings reset is required by this release. Published tags and npm versions remain immutable.

## 한국어

Redpact의 중심 경험을 GPT 내장 뷰어와 테스트 환경 관리에 맞췄습니다.

- 작업공간 탭을 제거하고 Desktop Full·Half View 모두 한 줄인 공용 헤더를 사용합니다. 탐색·뷰어 제어를 간결하게 정리하고 Unit·Integration 이름과 맨 오른쪽의 공통 Play 작업을 사용합니다.
- 내장 뷰어는 모든 너비에서 사이드바가 접혀 시작합니다. 크기를 바꿔도 수동 전환 상태를 유지하며 다시 열면 접힌 상태로 돌아갑니다.
- 일반 진단은 닫을 수 있는 오른쪽 아래 알림과 Settings의 Problems 이력으로 옮겼습니다. 연결을 막는 오류에는 복구 제어를 유지합니다.
- 정확한 소스 head·저장소·대상과 로컬 메인에 들어온 병합 결과를 확인해 squash·rebase PR 병합을 인식합니다. 새 커밋과 dirty 워크트리는 남기며 Git Graph는 실제 부모 관계를 유지합니다.
- dev/main 배포 흐름을 도입했습니다. dev는 검증하며 main은 안정 버전 준비, 정확한 스냅샷 검증, 태그 생성, 검증한 npm 아티팩트 게시와 레지스트리 무결성 확인을 자동 수행합니다.
- npm에 게시되지 않았던 0.10.0 스냅샷의 안전한 런타임 마이그레이션·원본 백업·Git 출력 한도 설정·실행 진단 개선도 포함합니다.

정확한 릴리스 workflow와 아티팩트 식별 정보에 검증 근거가 연결됩니다. 로컬·관리형 인수 검증은 관련 뷰어·병합 추적 흐름을 다루며, 릴리스 workflow는 Ubuntu/Node 24에서 설치 패키지를 검증합니다. 실제 ChatGPT 호스트의 capability 강제와 다른 OS/Node 조합은 이 근거의 범위가 아닙니다. GitHub PR 보완 판정에는 인증된 gh가 필요하며, 근거가 없거나 지원하지 않으면 작업을 계속 표시합니다.

설치 런타임을 업데이트하고 Plugin·스키마 변경 후 호스트를 다시 연결하세요. Plugin이 요구하는 런타임이 없거나 미게시 상태이면 Install Redpact가 나타나며, 전역 CLI와 Plugin 관리 런타임은 별개입니다. 기존 설정과 실행 이력은 보존하며 이번 릴리스 때문에 프로젝트 설정을 초기화할 필요는 없습니다. 게시한 태그와 npm 버전은 변경하지 않습니다.
