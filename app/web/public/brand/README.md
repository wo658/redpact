# Red Pact assets

- `wordmark.svg`: monochrome Inter semibold wordmark with its font embedded. Use as a CSS mask to inherit foreground color across themes.
- `icon.svg` and `icon.png`: app icon assets with a solid purple background (`#7772D5`).
- `/favicon.svg`, `/favicon.ico` and `/apple-touch-icon.png`: browser and home-screen registration. The touch icon uses the 256px icon export.

Preserve `Inter-LICENSE.txt` when redistributing the wordmark.
