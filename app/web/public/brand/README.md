# Red Pact assets

- `wordmark.svg`: monochrome Inter semibold wordmark with its font embedded. Use as a CSS mask to inherit foreground color across themes.
- `icon.svg` and `icon.png`: Aurora app icon, copied from the desktop sources.
- `/favicon.svg`, `/favicon.ico` and `/apple-touch-icon.png`: browser and home-screen registration. The touch icon uses the existing 256px desktop export.

The desktop source remains `app/desktop/icon.svg`; native bundle icons remain in `app/desktop/src-tauri/icons`. Preserve `Inter-LICENSE.txt` when redistributing the wordmark.
